**Run a coding agent. Check what it did.**

Kohyr runs a bounded coding job in a separate worktree, checks the result, and
returns one outcome for you to inspect and apply. An optional Kohyr Seal signs
the run's event chain with Ed25519 under a stated key and can be checked
offline. A Seal records integrity; it does not prove correctness.

`separate worktree` &nbsp;·&nbsp; `checked outcome` &nbsp;·&nbsp; `optional signed Seal`

Status: private and pre-alpha. Not released.
